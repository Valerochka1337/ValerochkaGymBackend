# Админка backend

- Интерфейс /admin/ в том же сервисе, русские формы, адаптивная навигация.
- Явное назначение is_admin существующему подтверждённому аккаунту оператором сервера.
- Google/email-вход, отдельная HttpOnly Secure SameSite cookie на 8 часов; проверка роли
  и отзыва сессии на каждом запросе. Origin и привязанный к сессии CSRF-токен для изменений.
- Сводка; поиск и пагинация пользователей и записей всех шести типов; карточка пользователя,
  просмотр сессий и их отзыв. Никаких паролей, токенов и кодов в admin API.
- Создание и редактирование упражнений и залов выбранного пользователя через SyncService,
  проверка revision, связей и идемпотентность повторов. Остальные агрегаты доступны для чтения.
- Атомарный аудит с автором, причиной и содержимым до/после. История сохраняется при удалении аккаунта.
- PostgreSQL integration tests для прав доступа, CSRF, отзыва роли/сессии, синхронизации,
  конфликтов, идемпотентности и атомарного аудита. Проверка UI в браузере.
- Документация назначения администратора, настройки Google Web origin и эксплуатации.
