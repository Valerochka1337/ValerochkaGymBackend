# Вход в админку по логину и паролю

Запрос: убрать Google из админки, задать логин `admin` и предоставленный владельцем пароль хэшем в БД.

- [x] Отдельные admin_credentials с Argon2id; связь с существующим владельцем для ролей и аудита.
- [x] Убрать Google UI, endpoints и внешние CSP-разрешения только из админки.
- [x] Сохранить cookie, Origin, CSRF, rate limits и отзыв ролей/сессий.
- [x] Операторский скрипт принимает готовый хэш через stdin, закрывает старые браузерные сессии.
- [x] Обновить документацию и CI-доставку скрипта.
- [x] Проверки: 25 JVM/PostgreSQL-тестов, 6 DOM-тестов; создание/смена хэша и отказы операторского скрипта в отдельной PostgreSQL.
- [ ] CI, деплой, установка хэша и проверка production-входа.

Пароль и его хэш не хранятся в репозитории и миграциях. Google и пароль Android-аккаунта не меняются.
